# Chúc mừng 20/11 — 3D (React + Three.js)

```bash
npm install
npm run dev      # chạy thử
npm run build    # build ra thư mục dist/
```

- `src/App.jsx` — giao diện React (form, lời chúc, nút điều khiển)
- `src/Engine.js` — cảnh 3D: pháo hoa, phi thuyền, hành tinh, thiên hà, khung ảnh
- `src/helpers.js` — hàm tạo texture hành tinh, thiên hà…
- `src/music.js` — nhạc nền tự tạo bằng WebAudio

Three.js được cố định ở bản 0.128.0 để đúng API đang dùng.
